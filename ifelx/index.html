What is IFelxOS?

IFelxOS is an operating system based on Debian with updates to the interface, including the addition of a new package manager called xv4.sh. It will be used as the official package manager in IFelxOS 2 as a replacement for apt, but currently runs alongside apt. The system is raw and ready to use, estimated at 10–13 GB.

Goals of IFelxOS

1 — Build a New Package Manager

This is the first and most foundational goal. xv4.sh will become the primary package manager, replacing apt in future versions. All other goals depend on this foundation.

2 — Become an Independent Distribution

Making IFelxOS a fully independent Linux distribution — breaking out of the "remix" barrier, similar to how Ubuntu evolved from Debian.

3 — Integrate Artificial Intelligence

Artificial intelligence is spreading rapidly. IFelxOS aims to integrate AI assistance directly into the system to help both the user and system operations.

4 — Build Popularity

Growing a community and user base is essential for sustainability and further development of the project.

5 — Become Fully Independent (Like BSD)

The long-term vision: become completely independent from the Linux kernel and build IFelxOS as a standalone operating system.
